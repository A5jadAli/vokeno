# Spanish A1 coverage register

Status on 18 October 2026: **all requirements remain open; none represents approved or assessed new content**. Units 1–5 teaching is now authored locally, with review pending; see the [implementation ledger](spanish-a1-milestones.md). This does not close a row's later retrieval or independent-evidence requirement. Read with the [unit briefs](spanish-a1-units-plan.md) and [assessment specification](spanish-a1-assessment-review.md).

This is a requirement-level allocation, not a claim to have reproduced every PCIC entry. The full item-level audit is a release gate, especially because the source site was under maintenance during research. No source requirement may disappear because it does not fit the chosen unit count.

## How reviewers close a requirement

For every row, create an evidence record containing: requirement ID; source and exact section/column; intended reception/production scope; lesson and step IDs; later retrieval IDs; unseen task IDs; lexical/grammatical prerequisites; accepted regional alternatives; script and actual audio review; reviewer/date; issue resolution; content version.

Use statuses **planned → source checked → authored → language reviewed → assessment reviewed → piloted → approved**. “Appears in a dialogue” cannot close a productive requirement. “Passed a choice question” cannot close speaking. Content review and demonstrated learner performance are separate records.

When expanding the register, compare each A1 inventory entry against an existing row. Add a child requirement if needed. Explicitly distinguish productive core, receptive core, useful chunk, optional extension and not applicable. A2-column items and empty A1 cells must not silently become A1 requirements. Pronunciation and some cultural/learning inventories use broader stages rather than a simple A1/A2 split; document the appropriate selection method.

## Explicit scope exclusions and controlled bridges

Do not require productive mastery of the preterite/imperfect/perfect tense systems, subjunctive, conditional, full imperative paradigm, complex object-pronoun combinations, all uses of por/para, unrestricted comparison or native-speed colloquial listening. Selected courteous or practical expressions containing more advanced forms can be learned as labelled chunks, with a simpler core alternative.

`Ir a + infinitive`, detailed symptom expressions, comparative structures and expanded reflexive/irregular paradigms require explicit A1/A2 checking before authoring. A familiar phrase in a scene must not silently introduce a large assessment requirement. Spelling/phonetics explanations must also be accurate: prefer scoped rules with familiar examples over claims such as “you can pronounce any word perfectly once you learn these rules.”

## Open source-audit work

1. Obtain the complete PCIC pages when accessible, preserve the A1/A2 columns and compare every relevant entry with the rows above. Search snippets can lose column boundaries.
2. Resolve level/scope decisions, regional equivalents and any missing entry by adding or refining requirements, not by deleting the source concern.
3. Attach actual lesson/step/task IDs after authoring. Unit numbers alone are insufficient for approval.
4. Close linguistic, audio, assessment and learner-evidence reviews independently. No aggregate “100% A1 coverage” indicator until all mandatory requirements are resolved.

The release criterion is **zero unassigned mandatory requirements, zero unresolved critical language/assessment issues, and evidence for every assessed can-do**. It is not a promise that every learner will pass an external examination or encounter no unknown word.
