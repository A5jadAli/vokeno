# Spanish A1: assessment, native review and implementation

Companion to the [curriculum plan](spanish-a1-curriculum-plan.md), [100 session briefs](spanish-a1-units-plan.md) and [coverage register](spanish-a1-coverage.md). Status: specification for implementation and review, 18 October 2026.

Implementation now includes Units 1–5, optional speaking models, dictation, a three-field details form in Unit 3 and a five-field registration precursor in Unit 4. See the [implementation ledger](spanish-a1-milestones.md) and [pilot review packet](spanish-a1-units-1-3-review.md). No assessed oral evidence, complete checkpoint, full DELE W1 runner or DELE mock has been implemented. The tables below remain the specification for those later capabilities.

## Exam blueprint

Target: **DELE A1 general, format introduced in 2020**, rather than the school-age exam. Reconfirm the current specification before publishing a dated exam-preparation release. The current indexed official A1 page supplies the following structure. [Instituto Cervantes: A1 structure](https://controlcalidad.examenes.cervantes.es/es/dele/como-son-los-examenes/a1).

| Paper     | Time                                    | Tasks/items                  | Maximum |
| --------- | --------------------------------------- | ---------------------------- | ------- |
| Reading   | 45 minutes                              | 4 tasks; 5 + 6 + 6 + 8 items | 25      |
| Listening | 25 minutes                              | 4 tasks; 5 + 5 + 8 + 7 items | 25      |
| Writing   | 25 minutes                              | 2 tasks                      | 25      |
| Speaking  | 10 minutes, with 10 minutes preparation | 3 tasks                      | 25      |

The overall maximum is 100. The pass requirement is **at least 30/50 in reading + writing and at least 30/50 in listening + speaking**. Do not substitute an overall 60% average, or claim that 60% in each separate paper is the official rule. [General A1 guide, scoring section](https://examenes.cervantes.es/sites/default/files/DELE_A1_v2020_Guia-de-examen.pdf).

### Task families to support

The table below is a concise working description; it is not a replacement for the complete administration instructions. It uses indexed current-guide descriptions and the official 2020 model. [DELE A1 guide](https://examenes.cervantes.es/sites/default/files/DELE_A1_v2020_Guia-de-examen.pdf), [2020 Model 0](https://examenes.cervantes.es/sites/default/files/DELE_A1_v2020_Modelo0.pdf).

| ID  | Working task description                                     | Product requirement                                                                        |
| --- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| R1  | Short personal text, multiple choice                         | Keep stimulus available while answering; Spanish questions/options in full practice        |
| R2  | Match short messages/notices and statements                  | Shared option pool, extra alternatives and clear response editing                          |
| R3  | Match short descriptions/needs and texts                     | Several texts visible/retrievable without losing responses                                 |
| R4  | Find factual information in practical material               | Preserve programme/table layout; three-option selection rather than an old gap-fill format |
| L1  | Short conversations with image choices                       | Real image options; no answer-revealing text substitutes                                   |
| L2  | Match short messages to images                               | Stable shared image pool, including unused alternatives                                    |
| L3  | Match utterances with sentence continuations                 | Shared text option pool and controlled audio sequence                                      |
| L4  | Complete statements by selecting details from a conversation | Shared response options; do not substitute unrestricted dictation                          |
| W1  | Fill a personal-information form                             | Multiple labelled fields and relevant original responses                                   |
| W2  | Write a short message in response to a prompt                | Full response editor; required points; 30–40-word target                                   |
| O1  | Personal introduction                                        | Unscripted response from the learner's chosen identity                                     |
| O2  | Short topic presentation                                     | Preparation cues, then continuous speech                                                   |
| O3  | Conversation with interviewer                                | Responsive follow-ups, not a read-aloud script                                             |

Do not use Goethe card exchanges, IELTS long turns or the pre-2020 fourth oral task as substitutes for DELE A1. The official change notice confirms three oral tasks, 25-minute listening, three-option R1/L1 and closed-response R4/L4. [Cervantes: 2020 format changes](https://examenes.cervantes.es/a1a2/profesionales/a1.htm).

**Details requiring complete-document verification before mock authoring is frozen:** W1's exact length instruction (working authoring target: 15–25 words); stimulus lengths; examples and number of usable/unused options in every task; playback repetitions and pauses; exact oral task instructions and timing distribution; permissible preparation notes; rating scales and conversion/weighting procedures. These must come from the general A1 guide/model, not a school-age or 2014 document. Do not improvise missing details. The official preparation page provides models, audio and answer sheets for this check. [Official preparation materials](https://examenes.cervantes.es/es/dele/preparar-prueba).

### Three different assessment purposes

| Purpose               | Help and feedback                                                                               | What it can establish                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Lesson practice       | Models, translations, replay, hints and immediate feedback                                      | Participation, practice success and likely areas needing support                |
| Cumulative checkpoint | Fresh prompts; help permitted but logged; feedback after the relevant attempt                   | Specific can-do evidence under recorded conditions; targeted remediation        |
| Full exam simulation  | Verified section timing/audio rules, no instructional hints or answer feedback during the paper | Performance on an original mock under stated conditions; not an official result |

Never roll hint-assisted success, repeated exposure to the same mock, self-reported speaking or an interrupted simulation into an unqualified readiness result.

## Evidence and readiness

Create three original forms. **A** teaches exam navigation and can be reviewed openly. **B and C** are held back for unseen attempts on separate days, with remediation between them. Once a learner sees a form's answers it becomes practice material. Further readiness attempts need an unused equivalent form, not the same questions shuffled.

Each form needs a blueprint mapping all 13 task families, verified administration instructions, rights-cleared images/audio, an answer key and rationale, acceptable written responses, oral interviewer prompts, trained-rater guidance and a review history. Use original content. Link to official samples for familiarisation; do not copy them into the paid product without confirming rights.

Assess listening with audio and speaking with the actual recording. A transcript cannot reveal all pronunciation, hesitation, intelligibility or interaction features. AI feedback may suggest practice, but any readiness label needs validated scoring for the relevant task and population; until then, obtain trained human review of productive work or explicitly show that it remains unassessed.

For written and oral samples, compare performance against the current official descriptors. Use reviewers trained in ELE/DELE assessment; do not convert an invented five-star rubric into an official score. Calibrate using authorised official benchmark material and double-rate a sample; double-rate all borderline readiness decisions during the pilot. Resolve disagreements and track systematic rater drift.

Proposed **internal** guidance, to calibrate rather than market as validated prediction:

- Recommend an exam attempt only after two unseen, properly administered forms meet the official group thresholds and productive ratings are complete.
- Aim for a buffer of 35/50 per group and 15/25 per paper on those forms. These are conservative product hypotheses, **not official cut-offs or an established probability of passing**.
- A compensated weak paper should still trigger targeted practice even when the official group minimum is met. No single strong skill should hide a persistent weakness.
- Show scores, dates, conditions, skill priorities and uncertainty; do not display “Guaranteed pass” or award a DELE certificate. A course completion record must identify itself as internal.

### Useful learner feedback

“You included the day and place. The recipient still needs the time. Add that detail, then try a new message.”

“You understood prices in a café. Telephone numbers were harder without text. Practise a short contact-details task next.”

Use feedback tied to an observable action. “Your Spanish is weak” and a single unexplained percentage do not help a beginner choose a next step.

## Small authoring example for native review

This is an original **draft example**, not native-approved teaching content or an exam item. It shows the desired combination of natural language, manageable scope and transfer.

### Unit 6: order and check

**Situation:** a customer orders at a café. The menu shows coffee 40 pesos and bread roll 25 pesos. Audio should not read currency symbols mechanically. Preteach `con/sin`, the menu nouns and the service question as a chunk.

| Speaker  | Spanish                                      | Meaning                                             |
| -------- | -------------------------------------------- | --------------------------------------------------- |
| Barista  | Buenas tardes.                               | Good afternoon.                                     |
| Customer | Hola. Un café con leche y un pan, por favor. | Hello. A coffee with milk and a bread roll, please. |
| Barista  | ¿Para aquí o para llevar?                    | To have here or to take away?                       |
| Customer | Para aquí. Y el café sin azúcar, por favor.  | For here. And the coffee without sugar, please.     |
| Barista  | Claro. Son sesenta y cinco pesos.            | Of course. That's sixty-five pesos.                 |
| Customer | ¿Sesenta y cinco?                            | Sixty-five?                                         |
| Barista  | Sí.                                          | Yes.                                                |
| Customer | Gracias.                                     | Thank you.                                          |

Reviewer decision: choose a locally natural, pictured bread item and align the noun/translation/menu image. `Pan` can be too broad for an exact item; the visual context must remove ambiguity. Review actual audio for a natural confirmation question and clear numbers.

Teaching sequence: hear the exchange for purpose; check order meaning; notice `con/sin`; identify a changed order; ask for an item; confirm a total. The spoken service question is not an invitation to teach every use of `para` in this session.

Independent transfer: learner receives a different menu and preference; the barista asks a fresh choice question. Check whether the listener can determine item, quantity and preference, and whether the learner handles the reply. Saying the original script perfectly does not satisfy this task.

### Later W2 practice model, revealed after an attempt

Prompt: a friend asks whether you can meet at a café on Saturday, at what time, and where to meet. A possible original answer:

> Hola, Ana: Sí, puedo ir al café el sábado. Estoy libre a las cinco. ¿Nos vemos en la entrada? Quiero un té con leche. Hasta el sábado. Un abrazo, Omar.

Check meaning, required points, comprehensibility, register and taught language; do not exact-match this response. Other relevant times, places and standard regional variants can be valid. The model is for later units, after the necessary language has been taught.

## Native and pedagogical review protocol

Every unit needs both native-language review and level/assessment review. Ideally use a Mexican-Spanish reviewer for the base material, a Spain-Spanish reviewer for peninsular material and an ELE/DELE-trained reviewer for level boundaries and assessment. People may hold more than one role, but a single native speaker's preference is not automatically a universal rule.

| Review pass   | Required checks                                                                                                     | Evidence retained                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Source/level  | Correct A1 column or justified chunk/extension; prerequisites; every mandatory requirement assigned                 | Requirement IDs, source sections and scope decisions          |
| Language      | Natural register, grammar, punctuation, translations, semantic equivalence and accepted alternatives                | Reviewed script and resolved changes                          |
| Instruction   | One clear objective, manageable new content, meaningful feedback, no unexplained dependency                         | Step-level comments and beginner pilot notes                  |
| Items         | Unambiguous correct answers, plausible distractors, no unintended regional “wrong” answers or answer leakage        | Independent blind solve and rationale                         |
| Audio         | Listen to the actual generated/recorded asset: accent, sounds, stress, numbers, names, pace and speaker consistency | Asset hash, reviewer and verdict; regenerated clips rechecked |
| Images/layout | Correct object/details, readable Spanish, no colour-only answers, no visual clue giving away an unrelated item      | Media/version and accessibility review                        |
| Production    | Fresh writing/speaking possible; feedback judges the task; accepted variation not restricted to one script          | Rater samples and calibration decisions                       |
| Integration   | Correct next action, resume behaviour, review linkage, offline/adapted alternatives and honest progress             | Device walkthrough and relevant test results                  |

Block publication for an incorrect key, invalid prompt, critical factual/linguistic error, missing required audio, unassessed essential requirement, broken navigation or misleading readiness claim. Track minor editorial improvements separately so they are resolved without hiding blockers.

Do not generalise rules such as “all older people require usted,” “h never matters in any Spanish word,” or “native speakers always drop these sounds.” Check local norms and scope explanations. Preserve correct alternatives such as `reserva/reservación` where the task permits them. Recheck translations after every change to colloquial variants.

## Release decision

Publish the course as fully reviewed only when the coverage register has no unassigned mandatory requirements, all lesson and media reviews are resolved, assessments work under the verified specification and beginner pilots support the proposed learning load. Publish exam-readiness guidance only after its separate validation gates are met.

This plan can organise rigorous preparation. A plan, a native-speaker sign-off or a completed lesson counter alone cannot guarantee an external result or native-level fluency.
